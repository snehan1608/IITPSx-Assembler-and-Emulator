Project: IITPSx Assembler and Emulator

Claims:

I have implemented and tested all required features for both the assembler and emulator using strict C99 standards without warnings.

Run this in terminal for making asm.exe and emu.exe files-
gcc -std=c99 -pedantic -Wall asm.c -o asm
gcc -std=c99 -pedantic -Wall emu.c -o emu

Assembler (asm.c):
- Implements two-pass assembly, resolves forward label references, and computes PC-relative branch offsets.
- Supports all ISA instructions, standard labels, and the SET directive.
- Generates .o binary, .lst listing, and .log error logs; suppresses .o output if syntax or semantic errors occur.
- Detects duplicate labels, missing operands, undefined labels, and unused labels.

Emulator (emu.c):
- Loads 32-bit little-endian .o files into simulated memory.
- Initializes regSP to MEM_WORDS (65536) following an empty descending stack model, requiring an initial `adj` allocation before local stack writes.
- Accurately executes all arithmetic instructions (including mul and div).
- Explicitly intercepts division by zero and division overflow, logging runtime errors and halting safely.
- Detects illegal opcodes, out-of-bounds PC/memory access (including unadjusted stack access at address 65536), and infinite loops, producing a memory dump upon completion.

Known Bugs:
- None. Tested with Bubble Sort, Mean, Factorial, and error edge cases.
